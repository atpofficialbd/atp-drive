# ATP Drive 🚀

Professional Cloud Drive Application with Unlimited Storage, Advanced Security & Material 3 UI.

## Features
- 🔐 Advanced Folder Lock (PIN + Biometric + Encryption)
- ☁️ Multi-Cloud Integration (Google Drive, Dropbox)
- 🔍 Smart Filter & Search Engine
- 🎨 Material Design 3 Professional UI
- 📁 Photo, Video, Document Management
- 🌙 Dark Mode Support

## Tech Stack
- Kotlin
- Jetpack Compose
- Material 3
- Room Database
- WorkManager
- Biometric API

## Build
APK builds automatically via GitHub Actions on every push.
